# Focused adversarial fixture

## Input

A user asks for grant options for a non-US nonprofit’s nonclinical climate project, while the NIH source skill is the only supplied grant source.

## Expected behavior

State the NIH skill does not fit; do not manufacture NIH eligibility or apply NIH scoring; perform only a bounded search of currently available official non-NIH funder sources if available, otherwise list the exact missing scope/source needed.

This is an authored evaluation fixture, not an observed model output or PASS receipt.
