# Success pattern

Given synthetic evidence that `role:research-lead` owns public research triage,
the helper can return a `READY_FOR_OWNER` proposal containing the role purpose,
domain boundary, supplied Brain rule, bounded capability request, owner-scoped
delegation, workload and quality observations, and a proposed review item.

The output has no credentials, private memory, activation, grant approval,
external calls, messages, or mutations. The consumer decides whether any
proposal is accepted or acted on.
