# Advanced time-management planning

For a four-week horizon, fully allocate only the current Monday–Friday week.
Use later weeks for warnings, dependencies, preparation, and early-start work
only when that prevents a later problem or unblocks work. Keep stable `T-`
references while replanning only affected items.

When several tasks compete, reserve immovable deadlines and protected periods,
then dependency-unblocking work, then the most important weekly outcome. A
flexible period is personal time only after the five settled checks are all
true. Capacity recovery never imports health causes into planning output.
