# Time-planning failure patterns

- Treating a conversational hint as a committed task.
- Scheduling before resolving a dependency or hard deadline.
- Calling a task complete because an agent said it was complete without the
  required artifact or external receipt.
- Treating a flexible period as personal time while material operator work is
  still outstanding.
- Putting private calendar names, account IDs, or health data into a shared
  skill artifact.
