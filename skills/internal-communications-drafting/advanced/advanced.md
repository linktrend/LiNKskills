# internal-communications-drafting — method selection and source boundaries

Both create internal communications. Combine stakeholder sequence and audience-specific drafts; retain proposals versus approved announcements. Strongest active base: source row 23. Incorporated source-specific improvements are explicit in Phase 2; adjacent tasks remain out of scope.

## Integrated task controls

1. Capture what is changing, change type/magnitude, honest reason, effective date, reversibility and decision status. Identify materially affected versus merely informed audiences, impact, constraints, embargo/legal sensitivity and a named question owner.
2. Use current LiNKbrain company/brand guidance and recipient preferences. Select channels by urgency, complexity, audience, sensitivity, two-way discussion and durable record needs; do not assume every audience reads the same channel.
3. Plan impact-then-influence sequencing and manager enablement with talk track/FAQ before broad release when needed. Respect a verified embargo/disclosure constraint that requires simultaneous release. Assign owner/channel/date to every planned touchpoint relative to the actual effective date.
4. Prepare the relevant audience-specific pre-communication, announcement, FAQ and follow-up drafts. State what, why, who, action/deadline or no action, where to ask and next step; do not request feedback on a settled decision as if it can change.
5. Audit clarity, reading difficulty, jargon, hedging, tone appropriate to magnitude, accessibility, channel fit and factual consistency. Keep touchpoint counts contextual. Read back stored drafts and route required approval; this task does not authorize sending.

Source scripts remain copied evidence and are not automatically trusted executable tools. Read individual supporting assets when required; use granted native tools for actual work.
