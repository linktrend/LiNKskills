# Native interface

Tool labels are contract vocabulary. `read_file` maps to native `read`; `write_file` maps to native `write`/`edit` only for an approved draft artifact; `get_tool_details` maps to current native schema and owner toolcard inspection. `list_dir` is not callable. Use current supported consumer-owned profile/context/artifact interface only if exposed; otherwise return a draft proposal and exact gap. OpenClaw runtime remains SQLite-backed; no local profile or JSONL sidecar.
