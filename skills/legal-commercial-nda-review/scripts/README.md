# Offline output-contract helper

Sara does not call this script as a runtime tool. `helper_tool.py` is a LiNKskills validation helper for checking a supplied NDA-review output artifact against `references/schemas.json#/definitions/output`; it does not perform legal analysis or decide behavioral quality. Run it only from the LiNKskills validation environment when a fixture/artifact is supplied. Sara's available native interfaces remain those documented in `SKILL.md`.
