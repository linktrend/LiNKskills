# Known source-pattern hazards

CANSLIM published fixed weights/bands, score claims, bear-market cash mandate and buy/sizing bands without independent calibration; its free-tier call counts conflict (35 vs 40 names and 248 vs 283 calls) and API plan data is date-sensitive. FinViz maps to provider filters/URLs only: URL output is not retrieved securities/results, code validity/freshness is not verified, and examples may use stale filters. Batch Scanner requires an externally deployed Google Apps Script webhook and writes to Sheets; excluded. GARP v3.6 has an internal 3-deep-dive default versus five target lane slots, and demands FMP credentials, code execution, SQLite/file persistence, current data and publication bundles; these are outside the approved read-only/native-session scope.

## Repair rule

Separate verified observation, calculation, inference, scenario, and advisory. Never infer successful evaluation from structural validation.
