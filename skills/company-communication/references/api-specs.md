## Output boundary

The output is a draft with audience, status, claims, evidence pointers, choices,
uncertainty, owner, and next step. Consumers own Markdown/email/chat rendering,
delivery, schedules, recipients, and exact templates. The skill never sends,
publishes, approves, rejects, or changes an external system.
