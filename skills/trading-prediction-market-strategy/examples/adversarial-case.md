# Adversarial cases

If station timezone or bracket inclusivity is absent, do not report a contract probability as settlement-aligned. If model uncertainty overlaps fee-adjusted break-even, classify edge as indeterminate. If two contracts have offsetting payouts but incompatible settlement times or unmodeled collateral lock, call it relative value only, not arbitrage.

Expected conclusions are examples only; no evaluation has been run and no PASS is claimed.
