# Synthetic example: financial control test workpaper

**Request:** Prepare a factual test workpaper for fictional private entity `Example Studio`, control AP-07, period 2026-09, USD. The entity has not established SOX applicability.

**Population:** POP-1 lists INV-101 USD 2,000; INV-102 USD 3,000; INV-103 USD 1,500; INV-104 USD 3,500. Population count is 4 and total is USD 10,000; independent source POP-CTRL-1 reports the same count and total. The synthetic owner-approved plan tests all four items in the listed order.

**Control evidence:** Owner criterion is to investigate an AP-aging-to-GL difference over USD 100. Evidence AGING-1 total is USD 10,000; GL-1 is USD 10,150. Recomputed difference: `10,150 - 10,000 = USD 150`, which exceeds the supplied criterion by USD 50. EV-101, EV-102 and EV-103 contain reviewer signoffs; EV-104 has no retained reviewer evidence; no investigation record is supplied.

**Result:** Report a USD 150 unreconciled difference with no investigation evidence and a separate missing-review-evidence exception for INV-104. Cite each source ID. Do not infer intent, assign a deficiency severity, or assert SOX applicability. Prepare a discussion draft for the controller to resolve.
