# Scripts

No source script was adopted or executed for this draft. Upstream script paths listed in `references/source-provenance.md` remain inventory-only data. A future script requires direct source review, permission and license review, and a separately authorized implementation.

Original entrypoint filenames are preserved as `source_path` in the manifest; quarantined copies use `SKILL.source.md` so library discovery cannot treat them as active skills. Byte content and hashes are unchanged.
