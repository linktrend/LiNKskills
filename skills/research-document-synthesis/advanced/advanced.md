# Method-specific extension

## Applied method

1. Verify each document’s identity, date, version, scope, and completeness.
2. Read the source at the requested depth; record central claim, supporting evidence, assumptions, methods, and explicit limitations separately.
3. Build a source-by-claim matrix; preserve disagreement and distinguish author interpretation from observed result.
4. Test the argument for unsupported leaps, missing counterevidence, and comparability limits.
5. Synthesize around the user’s question rather than writing one disconnected summary per document.
6. Return traceable citations to source locations and flag anything not accessible or not verified.

## Focused support: synthesis, learning summaries, and citations

### Summary and claim map

For a short request, lead with the answer and then give the source-backed reasons and caveats. For multiple documents, organize around the question and themes, not one paragraph per file. A compact synthesis can carry: question and scope; main claims; evidence and methods; agreement and disagreement; limitations; decision-relevant implications; and unresolved sources. Map each material claim to its source and location, preserving competing claims rather than forcing consensus.

### Learning explanation

When the user asks for a plain-language explanation, explain the mechanism in ordinary terms, then check that the explanation still matches the source. An analogy is a teaching device, not evidence; state where it stops matching. Keep terminology and caveats that affect the conclusion.

### Citation handling

Retain source title/author, date or version, and a stable location such as page, section, table, or URL as available. Match the requested citation style when supplied; otherwise use a consistent readable citation. Verify each citation supports the adjacent claim and identify inaccessible sources or missing page locations. Do not invent bibliographic fields or claim full-text review when only an abstract was available.

## Scope guard

Separate supplied-corpus claims from any optional external context. Do not search outside the supplied documents unless the user asks.

If the requested method cannot be completed with available evidence or tools, return a bounded partial deliverable and name the precise gap. Do not replace a missing input with an invented value.
