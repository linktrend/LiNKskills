# knowledge-operations — method selection and source boundaries

Both manage operational knowledge quality/freshness. Preserve governance/audience and retrieval variants; Librarians own admission. Strongest active base: source row 21. Incorporated source-specific improvements are explicit in Phase 2; adjacent tasks remain out of scope.

## Integrated task controls

1. Inventory authorized knowledge metadata using an explicit reproducible as-of date: title/path, named owner, date, criticality, links and available usage window. Distinguish critical operating knowledge, core material, reference and historical archive; keep unknown classification visible.
2. Apply the owner-approved freshness policy by tier; propose one if absent without presenting upstream intervals or scores as adopted policy. Review load-bearing stale guidance before historical low-risk records.
3. Inspect missing owners, dead links, orphaned resources and duplicate topics. Use available traffic evidence to distinguish a navigation gap from unused material; missing usage is unknown, not zero.
4. Rank remediation by criticality, evidence, usage and effort. For genuine duplicates preserve useful content and stable navigation through the supported owner route; the Librarian retains admission and canon decisions.
5. Return the dated health/gap report, bounded remediation backlog, named accountable owners and follow-up date. No deletion, archiving, redirects or canon changes without the required owner authority; use the same as-of convention for comparable reassessment.

Source scripts remain copied evidence and are not automatically trusted executable tools. Read individual supporting assets when required; use granted native tools for actual work.
