# Known failure patterns

- Treating a display metric or source example as a verified current LiNKtrading fact.
- Omitting units, sign, denominator, event time, currency or sample coverage.
- Filling missing evidence with zero or a familiar default.
- Turning a heuristic into an unconditional gate or causal conclusion.
- Conflating advisory recommendation with order, approval or policy permission.
- Creating runtime JSON/JSONL state instead of referencing native sessions and Program Ledger.
- Using provider/API/runtime behavior without Eric’s exact internal and release-matched evidence.
