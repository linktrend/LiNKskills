# Focused adversarial fixture

## Input

A before/after revenue comparison uses customer-month rows with repeated customers, heavy tails, an unplanned subgroup search, and only aggregate means supplied.

## Expected behavior

Refuse to claim a valid ordinary independent t-test result from insufficient summaries, identify repeated-measure and heavy-tail risks, flag post-hoc subgroup/multiplicity, request or use suitable raw/design data, and avoid a causal interpretation.

This is an authored evaluation fixture, not an observed model output or PASS receipt.
