# Known-bad patterns

- Treating budget authorization, award ceiling, actual spend, encumbrance, and available cash as interchangeable.
- Combining currencies or period labels without a visible conversion/reconciliation.
- Applying a default F&A rate, base, exclusion, cost classification, or capitalization rule without current award-specific authority.
- Treating missing actual burn as zero or presenting forecast burn as actual.
- Declaring runway, cost allowability, funder compliance, capitalization, or project viability from incomplete inputs.
- Turning milestone/cash scenarios into stage-gate, investment, or continuation decisions.
- Writing to an accounting, award, bank, or program ledger.
- Creating JSON runtime state sidecars or executing upstream financial scripts.
