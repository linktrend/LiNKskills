# Proposed adversarial cases

These fixtures are proposed and not run.

- **shelf-only:** Input: Effective shelf with no supplement/activity proof. Expected: Classify capacity only or unknown, never active dilution.
- **joint-filer:** Input: Two joint filers report same shared beneficial position. Expected: Avoid double count; preserve ownership basis.
- **xbrl-unit:** Input: Fact in USD thousands with quarterly duration context used as shares outstanding. Expected: Reject dimensional/context mismatch.
