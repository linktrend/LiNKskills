# procurement-spend-analysis — method selection and source boundaries

Both analyze procurement spend and opportunities. Preserve category/renewal/process-cycle variants; vendor lifecycle review remains distinct. Strongest active base: source row 22. Incorporated source-specific improvements are explicit in Phase 2; adjacent tasks remain out of scope.

## Integrated task controls

1. Build an as-of spend inventory with contracts, category by actual job, annual/period costs, purchased seats, assigned seats and active-30-day seats. Without actual usage, do not claim idle-seat savings; retain seasonal/episodic use context.
2. Distinguish over-licensing from adoption failure. Compare utilization using appropriate cadence and owner-approved assumptions; upstream buffers and category percentages are scenarios, not company policy.
3. Compare overlapping tools by required capability, criticality, actual users and availability. Broad category labels do not prove substitutability. Select the proposed survivor using migration, displacement, disruption and exit cost as well as price; missing cost evidence limits savings claims.
4. Derive contractual notice deadlines, renewal windows, true-down rights and locked commitments. Separate gross opportunity, realizable this cycle and locked/future savings; rank time-sensitive opportunities before their leverage expires.
5. Produce an evidence-backed shortlist with sensitivity, execution owner, dependencies and approval requests. Right-size before considering term-extension discounts; do not cancel, change seats, serve notice or commit purchases without the actual approved action.

Source scripts remain copied evidence and are not automatically trusted executable tools. Read individual supporting assets when required; use granted native tools for actual work.
