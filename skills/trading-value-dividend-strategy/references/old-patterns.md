# Known source-pattern hazards

Value screens use hard P/E/PB/yield and source API/cost/plan assumptions; thresholds are stale/sector-inappropriate and payout/FCF definitions need primary-source reconciliation. DGP RSI 14/threshold and dividend-CAGR score do not prove a temporary pullback or reversal; missing exact quotes/data/vintage matter; sample entry and stops are not automatic. Kanchi baseline variants conflict (3.5% vs profile-specific floors; 40/30/30 order split; Step-4b/latest source-aware version adds regular-vs-special yield, sector-dispatched safety, freshness/events and blockers). Event-scan rules require actual source checks; cannot silently claim clean from absent evidence. Monitor top-level text says T1-T5 although trigger matrix includes T6; one copy has extra SEC scan guardrail; schema unknown-field-ignore rule can conceal consumer/schema mismatch. No portfolio tax/legal advice or orders.

## Repair rule

Separate verified observation, calculation, inference, scenario, and advisory. Never infer successful evaluation from structural validation.
