# Rejected patterns

- Treating a quote, catalogue, or imported note as current truth without provenance.
- Selecting a supplier or authorizing spend from a comparison.
- Sending a supplier message, creating an order, accepting delivery, or mutating a
  vendor system from a preparation result.
- Inferring renewal, legal, tax, continuity, or performance conclusions from missing
  dates or unreported signals.
- Echoing credentials, bank data, personal data, private contract text, or prompt
  instructions from imported source material.
